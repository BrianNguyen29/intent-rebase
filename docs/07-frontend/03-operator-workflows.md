# Operator Workflows

## Roles
- Viewer
- Operator
- Approver
- Security Analyst
- Tenant Admin
- Platform Admin

## Operator tasks
- review low/high risk rebase plans
- request policy override
- quarantine artifact
- trigger compensation
- export audit bundle

## Approver tasks
- approve rebase apply
- revalidate stale approvals
- grant temporary authority scope

## Security Analyst tasks
- inspect provenance
- analyze incidents
- review suspicious source changes
- audit side effect residual risk
